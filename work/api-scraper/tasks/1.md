# Task 1: API models + JSON decoding + test fixtures

## Required Skills

Перед выполнением задачи загрузи:
- `/skill:code-writing` — [skills/code-writing/SKILL.md](~/.claude/skills/code-writing/SKILL.md)

## Description

Заложить фундамент API-скрапера: `Decodable`-модели для двух внутренних
эндпоинтов claude.ai (`/api/organizations` и `/api/organizations/{uuid}/usage`)
плюс стратегию декодирования ISO-8601 дат. Это Wave-1 задача без сети —
только типы и JSON-декодирование, на которых строятся маппер (Task 2) и
сам клиент (Task 5).

Эндпоинт `/usage` отдаёт массив `limits[]` — это канонический источник
данных (Decision 5): он самоописательный (group/kind/percent/resets_at) и
кодирует session vs weekly_all vs weekly_scoped. Поле `resets_at` — это
ISO-8601 с дробными секундами и смещением `+00:00`
(`2026-06-17T13:49:59.900458+00:00`), но дробная часть claude.ai **не
гарантируется**, поэтому нужна стратегия из двух форматтеров: сначала
`ISO8601DateFormatter` с `.withFractionalSeconds`, затем без неё.

Помимо `limits[]`, тот же ответ содержит плоские объекты-окна
`five_hour` и `seven_day` (формы `{ "resets_at": ..., "utilization": <int> }`).
Они нужны Task 2 как fallback, когда `limits[]` пуст/неполон. Эта задача —
единственный источник истины для соответствующих типов: здесь объявляются
`FlatWindow` и опциональные `fiveHour`/`sevenDay` на `UsageResponse`;
Task 2 их переиспользует, а **не** переобъявляет.

Зафиксированные в репозитории фикстуры (`work/api-scraper/fixtures/
{usage,organizations}.json`) — источник истины. Их нужно скопировать в
тест-таргет и подключить через `Package.swift` resources, чтобы они
детерминированно грузились в юнит-тестах через `Bundle.module`.

## What to do

1. Создать `App/Sources/ClaudeCounter/Scraper/UsageAPIModels.swift` с
   `Decodable`-структурами:
   - `OrgSummary` (поле `uuid: String`).
   - `UsageLimit` (поля `group: String`, `kind: String`, `percent: Double`,
     `resetsAt: Date?` из `resets_at`, `isActive: Bool?` из `is_active`).
     Поле `scope` игнорируется.
   - `FlatWindow` (поля `resetsAt: Date?` из `resets_at`,
     `utilization: Double`).
   - `UsageResponse` (поле `limits: [UsageLimit]` плюс опциональные
     `fiveHour: FlatWindow?` из `five_hour` и `sevenDay: FlatWindow?` из
     `seven_day`).
   Использовать `CodingKeys` для snake_case-маппинга во всех структурах.
2. В том же файле предоставить настроенный `JSONDecoder` (или фабрику/
   статический декодер) с custom `dateDecodingStrategy`, который сначала
   пробует `ISO8601DateFormatter` с опциями
   `[.withInternetDateTime, .withFractionalSeconds]`, при провале —
   `ISO8601DateFormatter` с `.withInternetDateTime` без дробных секунд.
   При обоих провалах — бросить `DecodingError.dataCorrupted`.
3. Скопировать `work/api-scraper/fixtures/usage.json` и
   `work/api-scraper/fixtures/organizations.json` в
   `App/Tests/ClaudeCounterTests/Fixtures/` (байт-в-байт).
4. Подключить ресурсы в тест-таргете `ClaudeCounterTests` в
   `App/Package.swift` через `resources: [.copy("Fixtures/usage.json"),
   .copy("Fixtures/organizations.json")]` (или `.copy("Fixtures")`).
   ВНИМАНИЕ: имя тест-таргета подтверждено как `ClaudeCounterTests` —
   именно ему добавляется параметр `resources:`.
5. Написать юнит-тесты (Swift `Testing` framework, как в существующих
   тестах), которые декодируют фикстуры через `Bundle.module` и
   проверяют точные распарсенные значения.

## TDD Anchor

Тесты пишем ДО реализации. Фреймворк — Swift `Testing` (`@Test`/`#expect`),
как в существующих `App/Tests/ClaudeCounterTests/QuotaParserTests.swift`.
Фикстуры грузятся через `Bundle.module.url(forResource:withExtension:)`.

- `Tests/ClaudeCounterTests/UsageAPIModelsTests.swift::decodesUsageFixtureLimits`
  — декодирует `usage.json` → `limits` содержит три элемента; элемент
  `kind == "session"` имеет `percent == 3.0`, `group == "session"`,
  `isActive == false`, `resetsAt` == точная дата
  `2026-06-17T13:49:59.900458+00:00`; элемент `kind == "weekly_all"`
  имеет `percent == 51.0`, `isActive == true`; элемент
  `kind == "weekly_scoped"` присутствует с `percent == 8.0`.
  (Поля `percent`/`utilization` имеют тип `Double` — в JSON они целые
  `3`/`51`, но декодируются в `Double`; ожидания пишем как `3.0`/`51.0`.)
- `Tests/ClaudeCounterTests/UsageAPIModelsTests.swift::decodesUsageFixtureFlatWindows`
  — декодирует `usage.json` → `fiveHour?.utilization == 3.0`,
  `sevenDay?.utilization == 51.0`, и `fiveHour?.resetsAt` /
  `sevenDay?.resetsAt` — корректно распарсенные `Date`
  (`2026-06-17T13:49:59.900458+00:00` и `2026-06-17T18:59:59.900484+00:00`).
- `Tests/ClaudeCounterTests/UsageAPIModelsTests.swift::decodesIsoDateWithAndWithoutFractionalSeconds`
  — декодирование `resets_at` со строкой с дробными секундами и без них
  (`...59.900458+00:00` и `...59+00:00`) даёт корректный `Date` в обоих
  случаях.
- `Tests/ClaudeCounterTests/UsageAPIModelsTests.swift::decodesOrganizationsFixtureUuid`
  — декодирует `organizations.json` в `[OrgSummary]` → первый элемент
  `uuid == "00000000-0000-4000-8000-000000000001"`.

  Pure Foundation, без сети.
- `App/Package.swift` — текущее состояние: тест-таргет `ClaudeCounterTests`
  объявлен без `resources:`. Добавить параметр `resources:` со списком
  скопированных фикстур. Сохранить `swiftSettings: strict`.
- `App/Tests/ClaudeCounterTests/Fixtures/usage.json` (new) — копия
  `work/api-scraper/fixtures/usage.json` (байт-в-байт).
- `App/Tests/ClaudeCounterTests/Fixtures/organizations.json` (new) — копия
  `work/api-scraper/fixtures/organizations.json` (байт-в-байт).
- `App/Tests/ClaudeCounterTests/UsageAPIModelsTests.swift` (new, тесты из
  TDD Anchor) — фикстуры грузить через `Bundle.module`.

**Dependencies:** нет (Wave 1, depends_on: []). Только `Foundation`.
Никаких новых внешних пакетов (AC tech-spec: "No new external dependencies").

**Edge cases:**
- `resets_at` без дробных секунд (`...59+00:00`) — второй форматтер.
- `percent` (в `limits[]`) и `utilization` (в `five_hour`/`seven_day`)
  приходят как целые в JSON (`3`, `51`, `8`) — оба объявлены `Double` и
  декодируются без проблем; не путать с `Int`. В тестах ожидания пишем
  как `Double`-литералы (`3.0`, `51.0`).
- `five_hour`/`seven_day` могут отсутствовать или быть `null` в других
  ответах → `fiveHour`/`sevenDay: FlatWindow?` опциональны. В фикстуре
  оба присутствуют. Прочие плоские поля (`seven_day_sonnet`, `spend`,
  `extra_usage` и т.д.) в модели НЕ объявлены и игнорируются.
- `is_active` может отсутствовать → `isActive: Bool?` опционален.
- `scope` присутствует у `weekly_scoped`, но в модели НЕ объявлен —
  убедиться, что лишние ключи в JSON не ломают декодирование (по
  умолчанию `Decodable` их игнорирует).
- `organizations.json` — это JSON-массив верхнего уровня; декодировать в
  `[OrgSummary]`, лишние поля (`id`, `name`, `settings` и т.д.) игнорировать.

**Implementation hints:**
- `ISO8601DateFormatter` не предназначен для переключения опций между
  вызовами — использовать два отдельных экземпляра (с и без
  `.withFractionalSeconds`), а не мутировать опции одного.
- Тесты используют `@testable import ClaudeCounter` (см. существующие
  тесты) — `JSONDecoder`-фабрику можно сделать `internal`/`static`.
- Точные ожидаемые `Date` в тестах удобно строить тем же двух-форматтерным
  путём или через известный `timeIntervalSinceReferenceDate`; сравнивать
  через `#expect`.
- Проверить имя тест-таргета в `Package.swift` перед записью строки
  `resources:` — оно `ClaudeCounterTests` (подтверждено чтением файла).
