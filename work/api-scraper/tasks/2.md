# Task 2: limits[] → ClaudeUsage mapper

## Required Skills

Перед выполнением задачи загрузи:
- `/skill:code-writing` — [skills/code-writing/SKILL.md](~/.claude/skills/code-writing/SKILL.md)

## Description

Add a pure, deterministic function that maps a decoded `UsageResponse`
(from Task 1's `UsageAPIModels`) into the existing `ClaudeUsage` domain
model. This is the single place that decides which `limits[]` entry feeds
the menu bar's current vs weekly numbers, mirroring Decision 5 of the
tech-spec (canonical source is `limits[]`, flat fields are the fallback).

The mapper is the counterpart to the retained `QuotaParser` (DOM-scrape
path): both produce a `ClaudeUsage`, both are pure and Sendable, both
inject `now` so tests can pin time. `UsageAPIClient` (Task 5) will call
this mapper after decoding; keeping the mapping logic isolated here means
it can be unit-tested with no networking and no `URLSession`.

No network, no WebKit, no shared state — Foundation only.

## What to do

- Create `UsageMapper.swift` as an `enum` with a `static func map(...)`
  (mirror `QuotaParser`'s shape: enum with a static `parse`, injected
  `now: Date = Date()`).
- Map the current (5h) window from the `limits[]` entry with
  `kind == "session"`: its `percent` → `currentPercent`, its `resetsAt`
  → `currentResetAt`.
- Map the weekly window from the entry with `kind == "weekly_all"` —
  explicitly NOT `weekly_scoped`. Its `percent` → `weeklyPercent`, its
  `resetsAt` → `weeklyResetAt`.
- `resetsAt` is already a parsed `Date` (Task 1's decoder handled
  ISO-8601 with/without fractional seconds), so assign it straight
  through — no minutes math, no re-parsing.
- Convert `percent` (`Double`) → `Int` by truncation, matching the
  existing `QuotaParser` behaviour (`Int(2.9)` → `2`).
- Set `updatedAt` to the injected `now`.
- Fallback: when a `limits[]` entry of the needed `kind` is absent, fall
  back to the flat top-level fields (`five_hour` for current,
  `seven_day` for weekly) — read their `utilization` (percent) and
  `resets_at`.
- Failure signal: if neither a usable `limits[]` entry nor a flat
  fallback field is present (empty/garbage), return `nil` so the caller
  can surface `.decodeFailed`.

  of `2.9` maps to `currentPercent == 2`.
- `UsageMapperTests::test_empty_limits_no_flat_fields_returns_nil` —
  empty `limits[]` and no flat fields → `nil`.

**Files:**
- `App/Sources/ClaudeCounter/Scraper/UsageMapper.swift` (new) — the mapper.

**Dependencies:**
- DEPENDS ON Task 1 (`UsageAPIModels.swift`): `UsageResponse`, `UsageLimit`
  (fields `group`, `kind`, `percent: Double`, `resetsAt: Date?`,
  `isActive: Bool?`). Reference these types — do NOT redefine them.
- The flat-field fallback needs `UsageResponse` to expose the top-level
  `five_hour` / `seven_day` objects (each `{ resets_at, utilization }`,
  see `usage.json` lines 14-17 and 55-58). Task 1's Data Models snippet
  only lists `limits`. If those flat fields are NOT yet decoded on
  `UsageResponse`, do not add a parallel model here — coordinate to extend
  Task 1's `UsageResponse` with optional `Decodable` properties for them,
  and record the model change as a deviation in decisions.md.

**Edge cases:**
- `weekly_scoped` entry present alongside `weekly_all` — must be ignored;
  select strictly on `kind == "weekly_all"`.
- Multiple entries of the same `kind` — take the first match (document the
  choice; the fixture has at most one of each).
- `resetsAt == nil` on a chosen entry — pass `nil` through to the
  corresponding `*ResetAt`; do not fail the whole map for a missing date if
  a percent is present.
- Only a flat field present (no matching `limits[]` entry) → use the flat
  field; only `limits[]` present (no flat) → use `limits[]`; neither → nil.

**Implementation hints:**
- Mirror `QuotaParser.parse`: `enum UsageMapper { static func map(_ response: UsageResponse, now: Date = Date()) -> ClaudeUsage? }`.
- `Int(percentDouble)` truncates toward zero — same as `QuotaParser`'s
  `Int($0)`; do not round.
- Find entries with `response.limits.first { $0.kind == "session" }` etc.;
  keep selection predicates readable and named.
- Return `nil` only when there is genuinely nothing to show (no current AND
  no weekly from either source) so the caller maps it to `.decodeFailed`.
